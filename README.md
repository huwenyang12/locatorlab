
# locatorlab

一个轻量级的浏览器端元素定位调试工具，用于调试 CSS Selector、XPath，并生成 Playwright 定位代码。

## 功能

- CSS Selector 调试
- XPath 调试
- 可视化点选页面元素
- HTML 格式化与预览
- 自动生成 Playwright Locator
- 支持明暗主题切换
- 支持中英文界面
- 支持结果高亮、跳转与复制

## 使用方式

直接使用浏览器打开 `index.html`。

可以通过以下方式使用：

1. 粘贴 HTML 源码
2. 或上传 `.html`、`.htm`、`.txt` 文件
3. 输入 CSS Selector 或 XPath 进行匹配
4. 也可以使用可视化点选模式直接选择页面元素
5. 匹配后可以复制 CSS、XPath 或 Playwright 定位代码
